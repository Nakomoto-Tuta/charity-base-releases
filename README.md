# Charity Base

Desktop app for browsing the Australian register of charities (ACNC): search by name, ABN, email or city, filters, export to Excel / CSV / JSON, automatic updates from acnc.gov.au.

**Download:** [latest release](https://github.com/Nakomoto-Tuta/charity-base-releases/releases/latest)

| System | File |
|---|---|
| Windows 10/11 | `CharityBase-<version>-windows.exe` — run it, no installation needed |
| macOS (Apple Silicon) | `CharityBase-<version>-macos.zip` — unzip, then right-click the app → **Open** the first time |

The app ships with a ready-made database and keeps it up to date by itself (the «Updates» screen).
